# Clique Reader

Welcome to Clique.

Clique is a social app for sharing posts, stories, reels, events, chats, and creator insights in one place. This guide is written for people joining from the wait list so they can get from invite to first action quickly.

## Start Here

1. Open your invite link or sign in with the account tied to your wait-list entry.
2. Finish your profile setup.
3. Add a photo, a short bio, and a cover image.
4. Choose a few interests so your feed is relevant from the start.
5. Follow people, join a topic, and post your first story or update.

## What Clique Is For

- Sharing daily moments as stories
- Posting updates with text, media, hashtags, polls, or anonymous mode
- Discovering trending topics and communities
- Messaging people directly
- Joining events, reels, and discussions

## First-Time Checklist

- Use a clear display name and username.
- Pick an avatar that makes you easy to recognize.
- Add one line about what you care about.
- Select a cover image that reflects your profile.
- Follow a few people before you post, so your feed fills up fast.
- Tap a topic or hashtag to explore conversations around it.

## How To Use The App

### Feed

The home feed is where posts and stories appear from people and topics you follow.

### Stories

- Create a story with text, media, or both.
- Use hashtags to help people find your story.
- Keep it short and readable.

### Posts

- Write a post when you want something more permanent than a story.
- Add media when it helps the message.
- Use hashtags sparingly and clearly.

### Topics

- Topics collect posts around a subject.
- Tap a topic to see the latest related conversation.

### Messages

- Send a direct message when you want a private conversation.
- If someone has not followed you back, keep the first message short and useful.

## Wait List Onboarding Flow

If you are onboarding someone from the wait list, use this flow:

1. Confirm their invite or approval.
2. Ask them to complete profile basics first.
3. Prompt them to follow at least three people or topics.
4. Encourage one first action:
   - create a story
   - introduce themselves in a post
   - send one direct message
   - join a topic
5. Ask for feedback after their first session.

## Suggested Welcome Copy

You can use this in an email, in-app message, or wait-list handoff:

> You are in. Clique is ready for you.
>
> Set up your profile, follow a few people, and post your first story to get started.
> If you need help, open the app settings and use the Help section.

## Support

- Use the in-app Help page for app questions.
- Use the Settings page for privacy, account, and security options.
- Report bugs or onboarding issues before they become friction for new users.

## Internal Notes

- Keep onboarding steps short.
- Do not overwhelm new users with every feature at once.
- Prioritize profile setup, first follow, first story, and first message.
- Make the first 60 seconds feel useful.

This is a Flutter-based Social Media App with a sleek and modern design.

## Installation
To get started, you need to have [Flutter](https://flutter.dev/docs/get-started/install) installed on your machine. Then, follow the instructions below:

1. Open the terminal and navigate to the project folder.
2. Run the command `flutter packages get` to install the required packages.
3. Run `flutter run` to build and run the debug app on your emulator/phone
